BrutalFit - Sistema de Gerenciamento de Academia

O BrutalFit é um sistema desenvolvido em Python com integração ao MySQL, criado com o objetivo de auxiliar no gerenciamento de uma academia. O projeto permite o cadastro e controle de alunos e administradores, armazenando as informações em banco de dados para garantir organização e praticidade no gerenciamento.
O sistema conta com funcionalidades como cadastro de usuários, login com diferentes níveis de acesso, gerenciamento de informações dos alunos e consulta de registros armazenados no banco de dados. O projeto foi desenvolvido como atividade acadêmica para aplicar conceitos de programação, banco de dados relacionais, CRUD e integração entre Python e MySQL.

Objetivo
Desenvolver uma solução simples para gestão de academia, colocando em prática conhecimentos de desenvolvimento de software, modelagem de banco de dados e manipulação de dados.
